# Rënia e lirë

Detyrë laboratori në fizikë. Punoi: **Dion Durma**

Tre objekte (pupla, zari dhe tapa e verës) hidhen nga e njëjta lartësi, fillimisht veç e veç dhe pastaj të vendosura mbi një fletore. Faqja përmban:

- qëllimin, teorinë dhe formulën t = √(2h/g)
- mjetet dhe ecurinë e punës
- një simulim të rënies (veç e veç / mbi fletore)
- tabelën e matjeve me mesataren dhe g = 2h/t²
- grafikun krahasues, vëzhgimet dhe përfundimin

Hape `index.html` në shfletues, ose shiko faqen në GitHub Pages.
